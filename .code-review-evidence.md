## Root Cause
Server was registered globally (user scope) but crashed on startup because CWD is ~ (home dir)
when Claude Code spawns MCP servers. No config files or project markers exist in ~, so
loadConfig() threw → process.exit(1) before MCP handshake.

## Fix
1. index.ts: try/catch around loadConfig(), pass null to LspManager on failure
2. LspManager: accepts null config, defers extensionMap building
3. getClientForFile(): lazy auto-detection from file's parent directory
4. getAllClients(): returns empty when no config (instead of iterating undefined)
5. getClientForLanguage(): clear error message directing to file-based tools first
