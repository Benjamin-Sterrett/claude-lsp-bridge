# PR1: Foundation — Types, Config, Project Scaffolding

## Problem
claude-lsp-bridge needs a foundation layer: TypeScript types, config loading, URI/position utilities, and project scaffolding. All subsequent PRs depend on this.

## Approach
Create the project from scratch with pnpm, strict TypeScript, and the MCP/LSP dependencies. Focus on three code files:
1. `types.ts` — shared types + URI normalization + position encoding converter
2. `config.ts` — config loading with zod validation + workspace auto-detection
3. Project scaffolding — CLAUDE.md, AGENTS.md, .gitignore, example config
